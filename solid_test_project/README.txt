This was a project I developed to teach myself C sharp and practice composition over inheritance. It features an object Shape which form the base of three dimensional solids and an object Top which compose the parts in the z direction. These solids contain random walkers which cannot leave the solid and may or may not be self avoiding. Currently there are two pairs of random walkers. The first pair which move in a grid are called RandomWalker and SARandomWalker which are identical except the second is self-avoiding. The second pair is called ThetaRandomWalker and SAThetaRandomWalker which like the first only differ in one being self avoiding. The ThetaRandomWalkers randomly choose a theta and a phi which given a step size determines where they go next.
